# Google's icons, as test fixtures

Unmodified copies, for `IconTest`, under the Apache License 2.0 in `LICENSE` here (the
repository's own; it has no NOTICE file).

- `symbols-outlined/`, `symbols-rounded/`, `symbols-sharp/`: Material Symbols from
  `google/material-design-icons` at commit `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`,
  `symbols/web/<name>/materialsymbols<style>/<file>`: `star` unfilled and filled (`fill1`) in each
  style, and `search`.
- `icons-twotone/star_24px.svg`: the two-tone Material Icon, `src/toggle/star/materialiconstwotone/24px.svg`
  at the same commit.
- `downloaded/`: `home.svg`, `star.svg` and `favorite.svg`, saved with fonts.google.com/icons's
  Download button on 2026-11-25 (`favorite.svg` with the site's default parameters).
