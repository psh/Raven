# samples/components

Port Raven's `examples/components`: cards, badges and stats, which the C example declares as XML
`<Widget>`s, become ordinary composables, and "Add a card" adds one. Spec:
[10. Samples](../spec.md#10-samples),
[8: Surface, FlowRow and Expander](../spec.md#phase-2-surface-flowrow-and-expander).

**Depends on:** [Surface, FlowRow and Expander](0064-surface-flowrow-and-expander.md).

## Deliverables

- [ ] `samples/components` with the C example's look, 760 by 560: the dashboard title and "Add a
      card", the cards in a `FlowRow` inside a `VerticalScroll`, the status line, and the source
      pane in an `Expander`.
- [ ] The sample's own composables, built on `Surface`, `FlowRow`, `Row` and `Text`:
      `Card(title, badge, wide, footer: @Composable RowScope.() -> Unit, content)` (the `footer`
      slot replaces `Into="footer"`), `Stat(label, value, trend)`, `Badge(text, color)` and
      `PersonRow(name, role, online)`.
- [ ] `<Repeat>`, `<ForEach>` and `{...}` expressions become Kotlin loops and string templates.
- [ ] Added cards are app state, a `mutableStateListOf<CardData>()` shown with `key(card.id)`:
      "Add a card" appends the next title and stats as the C code does, and a card's "Remove"
      removes it from the list.
- [ ] The source pane shows the Kotlin call that composes the last card added, generated by the
      sample from its `CardData`, in a read-only `CodeEditor(language = "Kotlin")` under "The Kotlin
      of the cards added".
- [ ] The status line starts with a hint and reports each add and remove.
- [ ] Runs from Gradle like `samples/hello`, documented in `compose/README.md`.
- [ ] A headless test: "Add a card" adds a card with the next title and shows its Kotlin, and its
      "Remove" takes it away.

## Gaps

- **Phase 3:** the cards' `Appear="Pop"`/`"Drop"` transitions and `AppearDelay`
  (`Modifier.appearTransition`, [Island and appear transitions](archive/0036-island-and-appear-transitions.md)).
- **Not yet settled:** the window's minimum size ([Window minimum size](0083-window-minimum-size.md)).

Building an XML document from code and the registry of declared `<Widget>` tags have no
counterpart, since a card is data and a composable, and are no gaps
([The components sample's source pane](archive/0078-the-components-samples-source-pane.md)).
