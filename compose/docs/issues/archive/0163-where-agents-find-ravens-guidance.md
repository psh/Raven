# Where agents find Raven's guidance

## Question

When an agent runs one of the skills in a Raven project, how does it learn the Raven equivalent of
a web step (Playwright, a screenshot, a dev server, a test runner)?

- **A Raven project skill** (`.claude/skills/raven/` or similar) that the skills' steps lead to, notes
  in `CLAUDE.md`/`AGENTS.md`, or both? Use `writing-for-agents`.
- **Where**: the Raven repository root (all of Raven), `compose/` (compose-raven), an app's own
  repository (shipped with the bindings or the packages), or several of these.
- **What it holds**: the audit's table turned into instructions, by language: how to see, drive and
  test a Raven app, and how to run a sample.
- **Keeping it true**: how it stays in step as the API and the skills change.

## Resolution

Decided with Paul on 2026-11-18, and written into
[`compose/docs/agent-skills.md`](../../agent-skills.md#guidance-for-agents).

- **A `raven` skill**: its description is the pointer. The body opens with a translation table from
  the skills' web words (Playwright, a screenshot, a dev server, the test runner) to preview,
  accessible, selector and idle, and caches only what can't be looked up (which tool answers which
  step, and the gotchas). Signatures and flags stay in the headers and `--help`. An `AGENTS.md` or
  `CLAUDE.md` holds at most a one-line pointer.
- **Shipped as a Claude Code plugin** from the Raven repo's root (`agents/raven/`, with the manifest
  in `.claude-plugin/`), versioned with Raven and proposed upstream.
- **Languages: main Raven's.** One disclosed file each for C and the 12 bindings, generated by
  `tools/bindgen` from one template. C, Python and Rust show their harness; the other ten show their
  `--test` example's pattern through the driver. **compose-raven is deferred** (later, if needed).
- **The map's verified languages become C, Python and Rust.** The other ten are covered by generated
  guidance. A harness for them, and compose-raven in the skill, go to the fog.
- **Two documents**: `agent-skills.md` is the design, the skill is for agents, and reviewing the
  skill is a checkbox in the design.
