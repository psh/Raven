# The raven agent skill

How an agent running the Matt Pocock skills in a Raven project finds Raven's way to see, drive and
test a UI. Design: [Guidance for agents](../../agent-skills.md#guidance-for-agents). Use
`writing-for-agents`.

**Depends on:** [Previews: Rwindow_save_preview and raven_preview](0170-previews.md),
[UI tests in Python: raven_testing](0172-ui-tests-in-python.md),
[UI tests in Rust: raven::testing](0173-ui-tests-in-rust.md),
[The UI tools in the Raven MCP library](0176-the-ui-tools-in-the-raven-mcp-library.md).

## Deliverables

- [x] `agents/raven/` at the repository root: `SKILL.md` with the pointer description, the translation table, and only what can't be looked up. (`skills/raven/`: see below.)
- [x] One file per language (C and the 12 bindings) generated by `tools/bindgen` from one template, with hand-written snippets for C, Python and Rust's harnesses.
- [x] The plugin manifest in `.claude-plugin/`, versioned with Raven.
- [x] The checkbox in `agent-skills.md` ticked against `raven_driver.h`.

## Resolution

Done on the `compose-raven` branch. `claude plugin validate .` passes; its one warning is that the
plugin has no icon. `bindgen.py --check` covers the generated files.

- **`skills/raven/SKILL.md`**, written with `writing-for-agents`:
  - **The description** is the design's pointer, its three branches (preview, drive, test) up
    front.
  - **The body**:
    - the design's translation table, in the leading words *preview*, *accessible*, *selector*
      and *idle*;
    - which tool answers which skill step (a test, a preview, variants, the running app over Raven
      MCP, with the `claude mcp add` line);
    - the selectors in one line;
    - the gotchas: headless and 77, idle and callbacks, real input, warnings fail tests, XML
      first.
  - **What it doesn't repeat**: signatures and flags stay in `raven_driver.h`, `raven_test.h` and
    `raven_preview --help`.
  - **Language files** are disclosed, one per language, read only for the language in use.
- **Moved: `skills/raven/`, not `agents/raven/`.** The repository's root is the plugin's root,
  and a plugin's `agents/` holds subagent definitions. `claude plugin validate` loaded every
  language file as a broken subagent. `skills/` is where a plugin's skills are found with nothing
  to configure.
- **`tools/bindgen/gen_skill.py`** runs after the bindings and writes the 13 language files and
  `.claude-plugin/plugin.json` and `marketplace.json`, versioned from `CMakeLists.txt`.
  - **Each language file**: the hand-written snippet (`tools/bindgen/skill/<language>.md`), then
    the driver's calls as the binding spells them. That covers all of `raven_driver.h`, plus init,
    the time step, the error callback, idle, the preview and shutdown.
  - **Spellings are checked.** A spelling is written only when the binding (or a hand-written file
    beside it) declares it. Go's missing `Raccessible_describe` is listed as such, and Go's
    `InitHeadless` and C++'s `Window::save_preview` are given as their substitutes.
- **The snippets**:
  - **With a harness**: C, Python and Rust use theirs, and C++ uses C's, since `raven_test.h`
    compiles as C++.
  - **The other nine** run a test by hand and check by selector, counting matches of a selector
    that states what is expected. A shared paragraph lists what C's harness would have done.
  - **Run here and passing**: the C++ snippet (compiled against `examples/notes/notes_app.c`) and
    the Node.js one (`node --test`). C, Python and Rust are the tests of 0171–0173.
  - **Not run**: Java needs 22 (this machine has 17). Go, C#, Zig, LuaJIT, Odin, Bun and C3 have no
    toolchain here; they follow the idioms of their build-tested examples. C3's snippet uses plain
    `assert`s, because the binding declares its faults with a keyword I couldn't check.
- **The README** has an agent skill section with a local install line (nothing is released).
- **Kotlin/Native (compose-raven)** isn't covered, as designed. Asked about on 2026-11-24, and
  kept apart as [0188](../0188-compose-raven-in-the-raven-skill.md): `compose.md` and
  `renderPreview`.
- **Not here**: the skill isn't yet tried in a real session. That is
  [0182](0182-verify-the-skills-on-samples.md).
